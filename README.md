# 🔐 Smart Home Security & Automation System

This is an **Arduino-based Smart Home Security & Automation System** that integrates multiple features to enhance home safety and user convenience. It brings together a variety of sensors, modules, and control mechanisms — including radar detection, Bluetooth control, and automated home appliances — all in one compact and interactive prototype.

## 📌 Features

- 🔒 **Password Authentication System**  
  Create, reset, and verify passwords using the keypad. Unauthorized access is blocked.

- 📲 **Bluetooth App Control**  
  Use your smartphone to remotely control the system using a Bluetooth module.

- 🌡️ **Temperature-Based Fan Activation**  
  Automatically turns on a fan when temperature exceeds the threshold using a temperature sensor.

- 📡 **Radar Motion Detection**  
  Ultrasonic sensor with servo motor scans for movement and displays it on a radar interface on the laptop.

- 💡 **Automatic Lighting System**  
  Light-dependent resistor (LDR) detects darkness and turns on the lamp automatically.

- 🔊 **Voice-Activated Speaker**  
  Integrated speaker system with voice command support and alerts.

- 🔐 **Electronic Door Locking**  
  Solenoid lock control based on password validation and app-based triggers.

## 🧰 Components Used

- 2x Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- Servo Motor
- LDR Sensor
- Temperature Sensor (LM35)
- Solenoid Lock
- Relay Module
- Bluetooth Module (HC-05/06)
- Buzzer/Speaker
- Breadboard and jumper wires
- LCD Display (16x2)
- Custom Mobile App (for Bluetooth control)
- Radar UI on Processing IDE

---

## 📷 Project Overview

The hardware setup includes two Arduino boards connected to a radar system (for ultrasonic-based motion detection), solenoid door lock, power supply, and a user-friendly interface on a mobile app. A clear and neat wiring system connects all components with power modules, controlled via Arduino programming and mobile input.
